# Control checklist

- Left stick: move in the world, mouse in menus
- Right stick: look
- Touchpad: mouse in menus, press to click
- D-pad: menus and inventory only. Not the stick.
- Cross: jump, or select
- Circle: drop in the world, back in menus. Back does not drop.
- Square: swap hands
- Triangle: open inventory, or move the whole stack
- L2: use / place
- R2: attack / mine
- L1 / R1: hotbar
- L3: sneak
- R3: sprint
- Options: pause
- Create: player list

Right on this pad is stored as D-pad bit 11. Map D-pad if a direction is still wrong.
