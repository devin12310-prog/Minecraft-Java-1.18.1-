# PS5 Controller for Minecraft Java 1.18.1

Fabric client mod that lets you play with a Bluetooth PS5 DualSense controller.

## Version
**1.0.1-prerelease**

## Build
```bash
cd ps5controller
gradle build
```
Output jars: `ps5controller/build/libs/`

Or use the GitHub Actions workflow (Actions tab) which builds on every push.

## Controls (in-game)
| Input | Action |
|-------|--------|
| Left stick | Move |
| Right stick | Look |
| Cross | Jump |
| **L3** | **Crouch (hold)** |
| **R3** | **Sprint (toggle)** |
| Square | Swap hands |
| Triangle | Inventory |
| L1 / R1 | Hotbar |
| L2 | Use |
| R2 | Attack |
| D-pad up | Drop |
| D-pad down | Perspective |
| Create | Player list |
| Options | Pause |

## Menu
- Left stick: cursor
- D-pad: navigate focused widgets
- Cross / Square: left / right click
- Circle / Options: back (Esc)
- Right stick: scroll
